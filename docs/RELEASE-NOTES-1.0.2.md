## 安装与使用

- Windows x64，浏览器和中英文OCR资源随包提供，安装包约493MB。
- 未配置代码签名证书，Windows可能显示发布者未知。
- 升级保留本机数据，建议先在设置中备份数据库。备份不包含登录状态和API Key。
- 电脑关机、休眠或程序退出后无法采集；首次登录、过期与验证码需自行处理。
- 安装包不含个人课程数据库、登录状态、API Key或截图中的演示数据。
