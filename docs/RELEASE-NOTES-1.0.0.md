# 课期 1.0.0

Windows x64 本机学业任务汇总与提醒。安装包包含独立 Chromium 及本地中英文 OCR 模型，无需另装浏览器或 Python。

## 功能

- 自动发现并定时读取思源学堂、中国大学 MOOC 与 SPOC 中参加的课程，默认每30分钟扫描；登录状态有效期间无需逐门打开或点击同步。
- 作业、测验、考试、互评阶段和公告统一呈现；老师要求日期与系统截止分别保存、展示、完成和提醒。
- PDF文本/扫描页、DOCX正文/内嵌图片、XLSX与常见图片本地解析，日期候选可核对、可校正。
- SQLite持久提醒、桌面通知与通知中心、托盘、可选Windows登录启动、业务数据备份与恢复。
- 可配置AI辅助：DeepSeek默认，OpenAI/Anthropic协议兼容；按需发送选中任务文字，候选不能覆盖系统截止。
- 可选本机Bearer认证API：课程、任务、通知、状态、触发同步与AI分析。

## 已做验证

2026-10-27本机真实读取20门课程。安装版隐藏主窗口后完成多轮定时采集；期间出现的入口超时被记录并自动重试，历史任务保留。通知卡片点击由用户确认可进入正式应用通知中心，主进程记录了对应激活时间。

30项单元与8项集成测试通过，另有实际SQLite去重/版本/部分失败/重交/撤下日期/中断恢复、主进程备份恢复、桌面重启、打包浏览器/OCR及AI/API配置验证。AI上游使用本地模拟服务验证协议，未提供真实付费Key。

## 使用条件与边界

电脑需开机、联网且程序运行。关闭主窗口会收至托盘；从托盘退出后停止采集与提醒。首次登录、会话失效或验证码由本人完成；不能保证永久免登录。

网页可能限流、加载超时或改版，失败和最近完整成功时间在“课程与采集”中显示；旧数据会保留。历史快照不能当作实时核验结果。部分旧版SPOC公告按课程级汇总呈现，保留原文和来源，不能自动精准关联到某份作业。

单文件25MB，PDF最多30页，DOCX最多20张支持格式内嵌图片。旧DOC/XLS、PPT、压缩包、加密文档及复杂表格/模糊手写不保证自动识别。OCR和日期语义可能有误，候选须核对。

AI和本机API默认关闭，按需在设置启用。API Key只在应用内填写；备份不包含Key或平台登录状态。没有自动答题、代交作业或修改课程平台内容的功能。

当前未配置代码签名证书；安装包发布者可能显示未知。正常使用说明见项目`README.md`，验收明细见`RELEASE-VALIDATION.md`。没有声称完成24小时连续无人值守、实际Windows重启或真实付费AI调用验证。
