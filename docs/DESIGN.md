# 课期界面方向

以课程任务和两种期限为核心，采用浅蓝侧栏、白色任务区、双列期限记录。老师要求使用低饱和琥珀色边线，系统截止使用蓝色边线，颜色之外始终显示文字标签。侧栏四项导航固定；主要动作是查看期限和来源，而非装饰性统计。

基础色：背景#F6F8FC、正文#273A55、品牌#274F82、辅助#78879C、分隔#E0E6EF。中文使用本机微软雅黑UI，不依赖外部字体请求。标题30px、任务标题17px、正文13–14px，重要期限独立成行。图标使用Lucide SVG，键盘焦点可见，弹窗使用原生dialog，减少动态时关闭旋转效果。

ui-ux-pro-max检索匹配到Minimalism & Swiss Style及桌面dashboard适用建议；其营销首页Hero+CTA骨架不适用于任务应用，未采用。frontend-design用于检查语义层级，避免以装饰统计替代任务信息。设计以已确认的任务页、课程页、通知页、设置页覆盖真实空白、登录、采集中、失败、完成与日期冲突状态。
